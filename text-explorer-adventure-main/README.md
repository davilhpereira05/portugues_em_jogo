# Text Explorer Adventure

Crie um site educacional interativo, gamificado, colorido e responsivo sobre Coesão e Coerência Textual, destinado a estudantes do Ensino Médio, mas com uma experiência acessível e divertida também para o público infantil.

O site faz parte do projeto escolar "Português em Jogo".

Grupo 03 — Coesão e Coerência Textual
Integrantes: Arthur Seif e Alessandro

O objetivo é transformar o conteúdo de Língua Portuguesa em uma experiência de aprendizagem semelhante a um jogo educativo, combinando explicações, exemplos, recursos multimídia, atividades interativas, quiz, recompensas e um desafio final.

O site deve ser realmente funcional. Não criar apenas telas demonstrativas. Todos os botões, atividades, pontuação, progresso, quiz e desafios devem funcionar.

1. OBJETIVO EDUCACIONAL

O site deve ensinar:

O que é coesão textual;

O que é coerência textual;

Organização das ideias;

Conectivos;

Pronomes;

Retomadas;

Relações de sentido;

Como identificar problemas de coesão;

Como identificar problemas de coerência.

Explicar tudo com uma linguagem simples, clara e visual.

A ideia principal deve ser:

Coesão = conexão entre as partes do texto.

Coerência = sentido e organização das ideias.

O conteúdo deve ser adequado ao Ensino Médio, mas apresentado de forma que uma criança também consiga compreender os conceitos básicos.

Evitar textos excessivamente longos e linguagem acadêmica desnecessária.

7. FASE 1 — COESÃO

Explicar:

Coesão é a ligação entre as partes de um texto.

Usar uma comparação visual:

"Imagine que um texto é como uma corrente. Cada frase precisa estar ligada à outra para que tudo fique conectado."

Criar uma animação de peças de quebra-cabeça ou elementos se conectando.

Exemplo:

"Pedro estudou bastante. Por isso, conseguiu uma boa nota."

Destacar "Por isso".

Explicar:

"Por isso" conecta as duas ideias.

Criar uma atividade simples depois da explicação.

10. FASE 3 — PRONOMES E RETOMADAS

Explicar que pronomes podem retomar palavras e ajudar a evitar repetições.

Exemplo:

"Maria comprou um livro. Ela começou a lê-lo."

Destacar:

"Ela" retoma "Maria".

"lo" retoma "livro".

Mostrar visualmente setas conectando os pronomes às palavras retomadas.

11. JOGO — DETETIVE DOS PRONOMES

Criar uma atividade em que o estudante precisa descobrir a que palavra determinado pronome se refere.

Exemplo:

"Lucas encontrou seu cachorro. Ele estava muito feliz."

Pergunta:

"Quem é 'Ele'?"

Mostrar diferentes opções.

Ao acertar, mostrar uma animação de descoberta.

Ao errar, fornecer uma dica.

12. FASE 4 — COERÊNCIA

Explicar:

Coerência é quando as ideias de um texto fazem sentido juntas.

Criar exemplos visuais.

Exemplo coerente:

"Estava chovendo muito, então peguei meu guarda-chuva."

Exemplo incoerente:

"Estava chovendo muito, então coloquei óculos de sol para não me molhar."

Mostrar visualmente por que o segundo exemplo não faz sentido.

13. JOGO — CAÇA À FRASE ESTRANHA

Mostrar várias frases e pequenos textos.

O estudante deverá encontrar aquele que apresenta um problema de coerência.

Depois da resposta, mostrar uma explicação curta.

Criar diferentes níveis de dificuldade.
